An abelian group is defined by a [[set]] $G$ and a [closed binary operation](./closed-binary-operation.md) $+$ which respects the following properties:

1) Associativity: for all $a,b,c \in G$ then $(a + b) + c = a + (b + c)$
2) Commutativity: for all $a,b \in G$ then $a + b = b + a$
3) Identity: there exists an identity element $0 \in G$ such that for all $a \in G$ then $a + 0 = a$ and $0 + a = a$
4) Inverse: for all $a \in G$ there exists a unique inverse $-a \in G$ such that $a + (-a) = 0$ and $(-a) + a = 0$

Abelian groups are [groups](./group.md) with commutativity.
