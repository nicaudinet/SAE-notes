A monoid is defined by a [[set]] $S$ and a [closed binary operation](./closed-binary-operation.md) $+$ which are [associative](./associativity.md) and have an [identity-element](./identity-element.md) element.

For all $a, b, c \in S$:
1) $(a + b) + c = a + (b + c)$
2) $a + 0 = a$
3) $0 + a = a$

Monoids are [semigroups](./semigroup.md) with an identity element.
